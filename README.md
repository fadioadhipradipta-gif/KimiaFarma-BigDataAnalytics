# Kimia Farma - Big Data Analytics

Project ini dibuat sebagai bagian dari Final Task Project-Based Internship untuk menganalisis performa bisnis Kimia Farma pada periode 2020–2023 menggunakan Google BigQuery dan Google Looker Studio.

📌 Deskripsi
Analisis dilakukan dengan menggabungkan beberapa dataset utama (transaksi, produk, inventori, dan kantor cabang) untuk menghasilkan tabel analisa. Hasil analisa ini divisualisasikan dalam bentuk dashboard interaktif sehingga memudahkan dalam melihat tren penjualan, profit, transaksi, serta kepuasan pelanggan.

📂 Struktur Repository
AnalyzedTable-Query.sql → Kode SQL untuk membuat tabel analisa di BigQuery
KimiaFarma-Analytics-Dashboard.pdf → Dokumentasi dashboard performa
Kimia Farma FINAL PROJECT.pdf → Laporan final project dalam bentuk presentasi
README.md → Panduan singkat repository

🛠️ Tools yang Digunakan
Google BigQuery → Data processing & analisis
Google Looker Studio → Data visualization
GitHub → Documentation & version control

🎯 Output
Tabel analisa transaksi, cabang, produk, dan profitabilitas
Dashboard interaktif Kimia Farma 2020–2023
Insight untuk mendukung strategi bisnis perusahaan
